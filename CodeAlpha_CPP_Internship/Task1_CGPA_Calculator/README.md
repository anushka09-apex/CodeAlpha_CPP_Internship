# CodeAlpha CGPA Calculator

## Description

This is a C++ console-based CGPA Calculator developed as part of the CodeAlpha C++ Internship.

The program allows users to enter multiple courses, their grades, and credit hours. It then calculates the total grade points and final CGPA.

## Features

- Enter multiple courses
- Enter grades and credit hours
- Calculate grade points
- Calculate total credit hours
- Calculate final CGPA
- Display course details
- Validate user input

## Technologies Used

- C++
- Standard C++ Library

## How to Run

1. Compile the program using a C++ compiler.
2. Run the generated executable.
3. Enter the number of courses.
4. Enter the course name, grade, and credit hours.
5. The program displays the final CGPA.

## Grade Point System

| Grade | Grade Point |
|-------|-------------|
| A | 10 |
| B | 8 |
| C | 7 |
| D | 6 |
| E | 5 |
| F | 0 |
